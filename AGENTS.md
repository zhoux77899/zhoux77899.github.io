# Working in this repository

For product behavior or visual changes, read `PRODUCT.md` and `DESIGN.md`.
For personal facts, project claims, publications, or travel records, read
`docs/content-sources.md`. Preserve its source boundaries and dated verification
records; illustrations do not establish personal history or project results.

For content, tooling, or illustration maintenance, read `docs/development.md`.
Edit tracked illustration sources and regenerate their outputs as documented.

Before handing off code or build changes, run `bun run check`. For interface
changes, also check the affected browser behavior, keyboard interaction, themes,
and reduced motion. Report the checks completed and explain any checks not run.
For documentation changes, verify commands and link targets against the repository.

Before committing or opening a pull request, read `CONTRIBUTING.md`.
