# Triage labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer evaluation |
| needs-info | needs-info | Awaiting information from the reporter |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use this mapping whenever an engineering skill refers to a triage role.
Preserve existing label metadata when adding missing labels.
